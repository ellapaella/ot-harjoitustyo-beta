# Requirement specifications

## Purpose of the application
This application is meant to be a program to visualize different probability distributions, namely the normal distribution, binomial distribution and poisson distribution. Other distributions are saved for later upgradeable updates if seen necessary.

## Users
There are only normal users, however the possibility to add an admin user remains plausible, but for now there is no need for admins.

## Basic version

### Not logged in

Users cannot view or save any probability distributions without creating a user account. All functionality needs an account.

### Logged in

After logging in the user can:

    - Logout from session
    - View different probability distributions
    - Modify probability distributions
    - Save probability distributions
    - Delete probability distributions
